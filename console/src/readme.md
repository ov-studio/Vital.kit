# Overview

The Vital.kit debug console, showing in-game logs.

Built with Vite and React. The result is a single `build/index.html` loaded by Godot.

## Usage

```
npm install
npm run dev       # develop with sample logs (runs without Godot)
npm run build     # outputs ../build/index.html
```

## Configuration

- `app/config.jsx` - default position, log limit and log delay
